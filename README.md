# OWKR Match

OWKR 내전 밸런스 조정 웹사이트입니다.

## 어떻게 사용하나요?

### 1단계: 디스코드에서 티어 정보 복사하기

디스코드에서 참가자들이 올린 티어 정보를 드래그해서 복사합니다 (Ctrl+C 또는 Cmd+C).
메시지 작성자 헤더까지 함께 복사하면 매칭표에 디스코드 닉네임과 배틀태그가 같이 표시됩니다.

```
테스터1#11853 다5/다1/다5
테스터2#38848 다3/마4/다4
테스터3#34981 미배치(골)/미배치(플)/플2
테스터4#31207 그5!/마1!/마4
```

> **티어 약어 설명**
> - `브` = 브론즈, `실` = 실버, `골` = 골드
> - `플` = 플래티넘, `다` = 다이아몬드, `마` = 마스터
> - `그` = 그랜드마스터, `챔` = 챔피언
> - 숫자는 등급 (1~5)
> - 순서는 항상 **탱커/딜러/힐러**
> - `!`는 선호 포지션, `?`는 비선호 포지션

### 2단계: 웹사이트에 붙여넣기

1. OWKR Match에 Discord 계정으로 로그인합니다
2. **채팅 붙여넣기** 탭의 텍스트 박스에 붙여넣기 합니다 (Ctrl+V 또는 Cmd+V)
3. **명단 가져오기** 버튼을 클릭합니다

Google Sheets 형식은 참가자를 바로 추가하는 용도가 아니라, 운영진이 계속 관리하는 **유저 시트**입니다.
상단의 **유저 시트 → 전체 시트 편집**에서 아래 6개 열을 그대로 붙여넣을 수 있습니다.

```
디스코드 표시명	배틀태그	탱커	딜러	힐러	특이사항
상만	Player#1234	다3	플2	플3	마이크x
```

저장된 유저는 목록에서 선택해 읽기 전용으로 조회하고, **시트 수정**을 눌러 전체 시트를 편집합니다.
현재 참가자와 같은 배틀태그가 시트에 있으면 참가자 카드에 시트 아이콘이 표시되며, 이를 눌러 해당 유저 정보를 바로 볼 수 있습니다.
유저 시트의 역할 티어에는 선호·비선호 기호를 저장하지 않습니다. 티어와 특이사항은 참고 정보이며
현재 팀 배정용 티어를 자동으로 바꾸지 않고, 특이사항은 배틀태그가 일치하는 대진표 선수 아래에도 표시됩니다.

전체 시트 편집의 **디스코드 명단 가져오기**에서는 참가자 입력과 같은 Discord 형식을 사용할 수 있습니다.
새 배틀태그는 신규 행으로 추가되고 기존 배틀태그는 디스코드 이름과 역할별 티어가 업데이트됩니다.
이때 기존 특이사항은 덮어쓰지 않고 그대로 보존됩니다.

디스코드 표시명은 중복될 수 있으며, 유저 시트와 현재 참가자의 연결에는 배틀태그를 사용합니다.
일반 채팅 복사본에는 Discord 사용자 숫자 ID가 포함되지 않으므로 참가자 식별에 사용하지 않습니다.

### 3단계: 팀 생성하기

1. 대기 명단에 **10명**이 모이면 **팀 짜기** 버튼이 활성화됩니다
2. 버튼을 클릭하면 자동으로 밸런스 맞춘 두 팀이 생성됩니다

### 4단계: 필요시 선수 교체하기

결과가 마음에 안 들면 선수를 직접 바꿀 수 있습니다.
- 교체하고 싶은 선수 A를 클릭
- 교체할 선수 B를 클릭
- 두 선수의 위치가 바뀝니다

### 5단계: 결과 공유하기

**이미지로 복사** 버튼을 클릭하면 결과가 이미지로 복사됩니다. 디스코드에 바로 붙여넣기 하면 됩니다.

## 선호 포지션 설정하기

특정 포지션만 하고 싶은 사람이 있다면, 해당 티어 뒤에 **느낌표(!)**를 붙이면 됩니다.

```
재봉이#31207 그5!/마1!/마4
```

위 예시에서 `그5!`는 "탱커 그랜드마스터 5등급, **탱커 선호**"라는 뜻입니다.
시스템이 최대한 해당 포지션에 배치하려고 노력합니다.

매칭 우선순위는 선호 포지션 위반, 비선호 포지션 배정, 미배치 포지션 배정을 차례로 최소화한 뒤 팀 점수와 역할별 차이를 맞추는 방식입니다.

## 자주 묻는 질문

**Q: 10명이 안 모이면 어떻게 하나요?**
A: 10명이 모여야 팀을 나눌 수 있습니다. 대기 명단에서 몇 명이 더 필요한지 확인하세요.

**Q: 데이터가 저장되나요?**
A: 현재 플레이어 정보는 로그인한 Discord 계정별로 브라우저에 24시간 동안 저장됩니다. 유저 시트와 관리자 공유 메모는 허용된 운영자가 함께 조회할 수 있도록 서버에 저장되고, 개인 메모는 작성자에게만 보입니다.

**Q: 미배치는 어떻게 입력하나요?**
A: `미배치(골)` 형식으로 입력하면 됩니다. 괄호 안은 예상 티어입니다.

**Q: 수동으로 한 명씩 추가할 수도 있나요?**
A: 네, **수동 입력** 탭에서 직접 티어를 선택해서 추가할 수 있습니다.

## 개발 및 배포

```bash
pnpm install
cp .env.example .env.local
pnpm dev:full
pnpm check
```

Discord OAuth, 유저 시트, 비공개 메모는 서버가 필요하므로 GitHub Pages가 아닌 Vercel에 배포합니다.
`main` 브랜치에 푸시하면 GitHub Actions는 타입 검사, 린트, 테스트, 빌드만 수행합니다.

### Discord OAuth 설정

1. Discord Developer Portal에서 OAuth2 애플리케이션을 만듭니다.
2. Redirect URI에 로컬은 `http://localhost:3000/api/auth/callback`, 운영은 `https://서비스도메인/api/auth/callback`을 등록합니다.
3. `.env.local`과 Vercel 환경변수에 `.env.example`의 값을 채웁니다.
4. `JWT_SECRET`은 32자 이상의 임의 문자열로 설정합니다.
5. 접근을 허용할 Discord 사용자 숫자 ID를 `ADMIN_USER_IDS`에 쉼표로 구분해 등록합니다.

OAuth는 로그인한 운영자의 Discord ID만 확인합니다. 채팅을 작성한 참가자들의 Discord ID를 수집하거나 추정하지 않습니다.

### 비공개 메모 저장소

Vercel Marketplace에서 Upstash Redis를 연결하면 `UPSTASH_REDIS_REST_URL`과
`UPSTASH_REDIS_REST_TOKEN`이 주입됩니다. 개인 메모는 로그인한 운영자 ID와
배틀태그 조합으로 분리되며, 관리자 공유를 선택한 메모만 등록된 다른 관리자가 볼 수 있습니다.

### 유저 시트

`유저 시트`는 참가자 입력과 분리된 운영진용 유저 정보 목록입니다. 시트에 저장된 티어와
특이사항은 팀 배정 데이터로 자동 반영하지 않으며, 현재 참가자와 배틀태그가 일치할 때 해당
유저의 참고 정보로 연결됩니다. 역할 티어의 선호·비선호 기호는 제거해 저장하며, 특이사항은
대진표와 복사한 대진표 이미지에 함께 표시됩니다.
